# Dossier « entrants »

Déposez ici tout document existant à intégrer à la conception de l'ERP :

- Ébauches Comptabilité (plan comptable, journaux, schémas d'écritures…)
- Maquettes / captures du Dashboard DAF
- Modèles de réquisitions, fiches d'avances à justifier, bons de caisse actuels
- Exemples de factures, états, rapports déjà utilisés dans le groupe
- Tout fichier Excel de gestion actuellement en service (ce sont des mines d'or pour comprendre vos règles réelles)

Formats lus sans problème : `.xlsx` `.xls` `.csv` `.docx` `.pdf` `.png` `.jpg` `.txt` + tout code source.

Une fois les fichiers déposés, dites simplement : « regarde les entrants ».
